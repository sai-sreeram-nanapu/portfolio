# Sai Sreeram Nanapu | Agentic AI Portfolio

A modern AI engineering portfolio for Sai Sreeram Nanapu, focused on Agentic AI, Generative AI, machine learning, cloud-native backends, APIs, automation workflows, and full-stack AI applications.

## Tech Stack

- Next.js App Router
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React icons

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm run start
```

## Deploy on Vercel

1. Push this repository to GitHub.
2. Import the repository in Vercel.
3. Keep the default framework preset as Next.js.
4. Use `npm run build` as the build command.
5. Deploy.

## Deploy on Render

1. Create a new Web Service on Render.
2. Connect the GitHub repository.
3. Set the build command to:

```bash
npm install && npm run build
```

4. Set the start command to:

```bash
npm run start
```

5. Set the environment to Node.

## Environment Variables

No environment variables are required for the current portfolio website.
